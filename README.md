# 테트리스

아이폰 사파리에서 **홈 화면에 추가**해 앱처럼 쓰는 테트리스입니다.
`index.html` 한 파일이 게임 전부이고, 빌드 도구도 외부 라이브러리도 없습니다.
파일을 브라우저로 열면 그대로 돌아가고, 정적 호스팅에 올리는 것이 곧 배포입니다.

## 조작

보드를 손가락으로 직접 만지거나, 화면 아래 버튼 줄을 씁니다.
버튼 줄은 ← ↻ → ↓ ⤓ 다섯 개와 맨 오른쪽 🏠(홈)입니다.

| 하고 싶은 것 | 손가락 | 키보드 |
|---|---|---|
| 좌우로 옮기기 | 보드를 좌우로 쓸기 · 아래 ← → (꾹 누르면 연타) | ←, → |
| 회전 | 보드를 톡 누르기 (0.2초 안에 떼기) · 아래 ↻ | ↑ 또는 X (Z는 반대 방향) |
| 내리기 | 보드를 꾹 누르고 있기 · 아래 ↓ | ↓ |
| 바로 내리기 | 아래로 훅 쓸기 · 아래 ⤓ | 스페이스 |
| 일시정지 | — | P 또는 Esc |

**누르고 있는 시간**이 곧 내려가는 속도입니다. 살짝 누르면 한두 칸만 내려가고,
계속 누르고 있으면 점점 빨라집니다(처음 0.15초/칸 → 0.9초 뒤 0.03초/칸).
꾹 누른 채 두면 바닥까지 1.2초쯤 걸립니다.

아이폰은 누르는 **힘**을 알려 주지 않습니다(3D Touch가 아이폰 XS·XR 세대부터
빠졌고 사파리도 터치 압력 값을 주지 않습니다). 그래서 힘 대신 누르고 있는
시간으로 세기를 표현했습니다.

톡 누르는 것과 꾹 누르는 것은 0.2초로 나뉩니다. 0.2초 안에 떼면 회전이고,
그보다 길게 누르고 있으면 내려갑니다. 좌우로 쓸기 시작하면 누르고 있던 것은
취소되니 옆으로 옮기다가 갑자기 떨어지지 않습니다.

홀드와 소리는 없습니다. 다른 앱으로 넘어가거나 화면을 끄면 자동으로 멈춥니다.

## 홈과 기록

게임 중에 오른쪽 아래 🏠 를 누르면 "시작 화면으로 가시겠습니까?"를 한 번 묻습니다.
**아니오**면 그 자리에서 바로 이어서 하고, **예**면 홈으로 갑니다.
**예를 누르면 하던 판은 사라집니다.** 홈은 언제 와도 처음 켰을 때와 똑같아서
버튼은 **시작** 하나뿐입니다. 기록이 있으면 옆에 **기록 지우기**가 같이 나오고,
누르면 한 번 되묻고 나서 전부 지웁니다.

홈에는 제목 아래로 조작법이 애니메이션으로 돌아갑니다. 작은 판에서 블록을 실제로
옮기고 돌리고 떨어뜨려 보여 주고, 한 장면씩 2.1초로 네 가지를 번갈아 보여 줍니다.

그 아래에는 기록 열 개가 펼쳐져 있습니다 — 순위 · 이름 · 점수 · 지운 줄 · 레벨 · 날짜.
글씨 뒤로는 블록들이 천천히 돌면서 떠다닙니다(`prefers-reduced-motion`이면 멈춥니다).
게임이 끝나고 점수가 상위 10등 안에 들면 이름을 적는 칸이 나오고(여덟 자까지),
저장하면 홈으로 돌아가 방금 넣은 줄이 보라색으로 표시됩니다.

기록은 **그 기기의 브라우저에만 저장됩니다**(`localStorage`). 폰과 컴퓨터가 기록을
같이 보려면 따로 서버가 있어야 합니다.

## 둘이서 (대전)

홈에서 **둘이서**를 누르면 방 번호 화면이 나옵니다. 한 사람이 **방 만들기**로
여섯 자리 번호를 받아 알려 주고, 다른 사람이 그 번호를 넣어 **들어가기**를 누릅니다.
둘이 만나면 3 · 2 · 1 을 세고 동시에 시작합니다.

줄을 지우면 상대 판 밑으로 **방해 줄**이 밀려 들어갑니다. 한 번에 들어온 방해 줄은
구멍 자리가 같습니다. 먼저 무너지는 사람이 집니다.

| 한 번에 지운 줄 | 보내는 방해 줄 |
|---|---|
| 1줄 (싱글) | 0 |
| 2줄 (더블) | 1 |
| 3줄 (트리플) | 2 |
| 4줄 (테트리스) | 4 |

T-스핀은 +2, 백투백은 +1, 콤보는 2콤보마다 +1 이 더 붙습니다.
내게 쌓일 차례를 기다리는 방해 줄이 있으면 **내가 보낼 줄로 먼저 상쇄**합니다.
다 막으면 "막았다!", 남으면 남은 만큼만 건너갑니다.
날아와서 기다리는 방해 줄은 보드 왼쪽에 빨간 막대로 보입니다.

대전 중에는 멈출 수 없습니다. 한쪽만 멈추면 공평하지 않기 때문입니다.
상대에게서 9초 동안 소식이 없으면 연결이 끊긴 것으로 보고 끝냅니다.

### 연결

Supabase Realtime 의 broadcast 를 그대로 씁니다. 표(table)는 만들지 않았고,
주고받는 쪽지는 지나가기만 할 뿐 어디에도 저장되지 않습니다. `index.html` 안의
`SUPABASE_URL` 과 `SUPABASE_KEY` 가 그 주소와 공개용(publishable) 키입니다.
공개용 키라 페이지에 들어가도 괜찮습니다. Supabase 대시보드에서 따로 설정할 것은
없습니다 — 프로젝트를 만들면 Realtime 은 기본으로 켜져 있습니다.

### 전적

한 판이 끝날 때마다 **상대 이름별로 몇 승 몇 패인지** 적어 둡니다.
**둘이서** 화면에 최근에 붙은 순서로 나오고("아빠 5승 3패"), 대전이 끝난 화면
아래에도 지금 상대와의 전적이 같이 나옵니다.

연결이 끊기거나 상대가 나가서 끝난 판은 **전적에 넣지 않습니다.** 그런 판에는
화면에도 "전적에는 넣지 않습니다"라고 적힙니다.

전적은 점수 기록과 마찬가지로 **그 기기에만 저장됩니다**(`localStorage`). 둘이
각자 자기 폰에 적으므로 서로 숫자가 같습니다. 홈의 **기록 지우기**를 누르면
점수 기록과 전적이 함께 지워집니다.

대전 점수는 혼자 할 때의 기록표에는 넣지 않습니다. 기록표는 혼자 할 때만 쌓입니다.

## 규칙

- 표준 SRS 회전 + 월킥, 7-bag 무작위, 고스트 조각 (다음 조각 미리보기와 홀드는 없습니다)
- 락 딜레이 0.5초(움직이면 15번까지 연장됩니다)
- 점수: 싱글 100 · 더블 300 · 트리플 500 · 테트리스 800 (레벨 배수),
  T-스핀과 백투백 1.5배, 콤보 50×콤보, 완전 클리어 보너스
- 10줄마다 레벨이 오릅니다. 한 칸 내려오는 시간은 1레벨 1.1초에서 시작해
  10레벨 0.18초, 15레벨 0.04초, 그 뒤로는 0.025초에서 멈춥니다

## 배포

정적 파일만 있으므로 GitHub Pages에 그대로 올립니다.

```
git add -A && git commit -m "..." && git push
```

Settings → Pages → Source: `main` / `/ (root)`

## 아이폰 홈 화면에 추가하기

사파리로 주소를 열고 → 공유 버튼 → **홈 화면에 추가**.
주소창 없이 전체 화면으로 뜨고, 아이콘은 보라색 T 블록입니다.
