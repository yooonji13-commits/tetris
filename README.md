# 테트리스

아이폰 사파리에서 **홈 화면에 추가**해 앱처럼 쓰는 테트리스.
`index.html` 한 파일이 게임 전부다. 빌드 도구도, 외부 라이브러리도 없다.
파일을 브라우저로 열면 그대로 돌아가고, 정적 호스팅에 올리는 것이 곧 배포다.

## 조작

조작은 보드를 손가락으로 직접 만진다. 화면에는 오른쪽 아래 **홈** 버튼 하나뿐이다.

| 하고 싶은 것 | 손가락 | 키보드 |
|---|---|---|
| 좌우로 옮기기 | 보드를 좌우로 쓸기 | ←, → |
| 회전 | 보드를 톡 누르기 | ↑ 또는 X (Z는 반대 방향) |
| 천천히 내리기 | 아래로 살짝 쓸기 | ↓ |
| 바로 내리기 | 아래로 길게 훅 쓸기 | 스페이스 |
| 일시정지 | — | P 또는 Esc |

아래로 쓸면 **손가락이 내려온 만큼** 한 칸씩 따라 내려온다. 손을 멈추면 같이 멈추니
원하는 자리까지 천천히 끌고 갈 수 있다. 세 칸 넘게 한 번에(0.26초 안에) 훅 쓸었을
때만 바닥까지 떨어진다.

홀드와 소리는 없다. 다른 앱으로 넘어가거나 화면을 끄면 자동으로 멈춘다.

## 홈과 기록

게임 중에 오른쪽 아래 **홈**을 누르면 "시작 화면으로 가시겠습니까?"를 한 번 묻는다.
**아니오**면 그 자리에서 바로 이어서 하고, **예**면 홈으로 간다.
홈으로 가도 하던 판은 버리지 않고 멈춰 둘 뿐이라 **이어 하기**로 돌아갈 수 있고,
**새 게임**으로 새로 시작할 수도 있다.

홈에는 기록 열 개가 그대로 펼쳐져 있다 — 순위 · 이름 · 점수 · 지운 줄 · 레벨 · 날짜.
글씨 뒤로는 블록들이 천천히 돌면서 떠다닌다(`prefers-reduced-motion`이면 멈춘다).
게임이 끝나고 점수가 상위 10등 안에 들면 이름을 적는 칸이 나오고(여덟 자까지),
저장하면 홈으로 돌아가 방금 넣은 줄이 보라색으로 표시된다.

기록은 **그 기기의 브라우저에만 저장된다**(`localStorage`). 폰과 컴퓨터가 기록을
같이 보려면 따로 서버가 있어야 한다.

## 규칙

- 표준 SRS 회전 + 월킥, 7-bag 무작위, 고스트 조각 (다음 조각 미리보기와 홀드는 없다)
- 락 딜레이 0.5초(움직이면 15번까지 연장)
- 점수: 싱글 100 · 더블 300 · 트리플 500 · 테트리스 800 (레벨 배수),
  T-스핀과 백투백 1.5배, 콤보 50×콤보, 완전 클리어 보너스
- 10줄마다 레벨이 오른다. 한 칸 내려오는 시간은 1레벨 1.1초에서 시작해
  10레벨 0.18초, 15레벨 0.04초, 그 뒤로는 0.025초에서 멈춘다
- 아래로 쓸고 있는 동안은 레벨과 상관없이 0.03초에 한 칸씩 내려온다

## 배포

정적 파일만 있으므로 GitHub Pages에 그대로 올린다.

```
git add -A && git commit -m "..." && git push
```

Settings → Pages → Source: `main` / `/ (root)`

## 아이폰 홈 화면에 추가하기

사파리로 주소를 열고 → 공유 버튼 → **홈 화면에 추가**.
주소창 없이 전체 화면으로 뜨고, 아이콘은 보라색 T 블록이다.
